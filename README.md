# Trading Dashboard

Streamlit dashboard for SSI trading analytics.

## GitHub files

Upload these files, then rename them in GitHub:

- `github_ready_app.py` -> `app.py`
- `github_ready_requirements.txt` -> `requirements.txt`
- `github_ready_gitignore.txt` -> `.gitignore`

Do not upload personal trading CSV/XLSX files to GitHub. Upload them directly inside the dashboard UI after deployment.

## Streamlit Cloud settings

Main file path:

```text
app.py
```
